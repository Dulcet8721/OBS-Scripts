# OBS-Scripts

Это набор Lua-скриптов для OBS Studio: сохранение частичных повторов, автоматическая сортировка файлов, визуальные и звуковые уведомления, сжатие видеофайлов через внешний FFmpeg, управление источниками, переключение видимости OBS по горячей клавише.

Все скрипты могут работать независимо, но некоторые вместе имеют интеграцию и образуют единую систему.

---

## Скрипты

### 🎬 Partial Replay

**Возможности:**
- Создаёт до трёх дополнительных буферов повтора с настраиваемой длиной.
- Отдельные горячие клавииши для сохранения каждого буфера.
- Иерархический сброс буферов после сохранения.
- Интеграция с Smart File Organizer и Notifier.

[Подробное описание Partial Replay →](../../wiki/Partial-Replay)

---

### 📁 Smart File Organizer

**Возможности:**
- Автоматическое создание папок с именами игр.
- Автоматическая сортировка записей, повторов, скриншотов и частичных повторов по папкам.
- Автоматическое разделение записи при смене фокуса с игры.
- Интеграция с Partial Replay и Notifier.

[Подробное описание Smart File Organizer →](../../wiki/Smart-File-Organizer)

---

### 🔔 Notifier

**Возможности:**
- Визуальные и звуковые уведомления сигнализирующие о сохранении файлов.
- Настройка позиции, размера, длительности и звука уведомлений.
- Интеграция с Partial Replay и Smart File Organizer.

[Подробное описание Notifier →](../../wiki/Notifier)

---

### 💾 External FFmpeg Compress

**Возможности:**
- Сжатие видеофайлов кодирировщиком x264.
- Настройка выходного разрешения и FPS. Настройка степени сжатия CRF. 
- Поддержка аппаратного ускорения декодирования.

[Подробное описание External FFmpeg Compress →](../../wiki/External-FFmpeg-Compress)

---

### 🔄 Source Switcher

**Возможности:**
- Автоматическое переключение источников.
- Автоматическое растягивание источников под размер сцены.
- Настройка черных списков процессов и сцен.
- Автоматическая проверка сигнала захвата экрана.

[Подробное описание Source Switcher →](../../wiki/Source-Switcher)

---

### 👁️ Toggle OBS UI

**Возможности:**
- Переключение видимости главного окна OBS.
- Опциональное переключение видимости окна `Скрипты` вместе с главным окном.

[Подробное описание Toggle OBS UI →](../../wiki/Toggle-OBS-UI)

## Установка

1. Скачайте архив `OBS-Scripts.zip`.
2. Распакуйте архив в любую удобную папку.
3. Откройте OBS Studio.
4. В меню выберите **Сервис → Скрипты**.
5. Нажмите **«+»** и выберите нужный `.lua`-файл.
6. Настройте скрипт как вам удобно и используйте.

[Подробная инструкция →](../../wiki/How-to-install)
